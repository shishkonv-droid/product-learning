# Синхронизация уроков из документа

Источник: Claude Doc «Продакт-менеджер: программа обучения на 6 месяцев»
(id `7331d73b-6edc-4477-84bd-bde4a4513a0a`, https://claude.ai/artifact/FE2zorBVc4RKNgsbihXgQ9).

Структура документа: вкладка «Tab 1» — программа (таблицы недель), вкладка «Уроки» с подвкладками
«Неделя N» — полные уроки недели.

## Шаги

1. Прочитать список вкладок документа (Claude Docs `read`, ref = project id).
2. Для каждой подвкладки «Неделя N», для которой нет файла `tools/src/weeks/week-NN.md`
   (или если текст вкладки изменился), прочитать её (`read` node, payload `{"kind":"view"}`)
   и записать в `tools/src/weeks/week-NN.md` (NN — две цифры) в таком markdown:
   - каждый урок начинается с `## Урок N · Дд ДД месяца · Название` (ровно как заголовок в документе);
   - подзаголовки — `### Теория (15 мин)` и т. п.;
   - абзацы, `**жирный**`, ссылки `[текст](url)`, списки `- ` и `1. `, цитаты/промпты `> `,
     таблицы `| a | b |` с строкой `| --- | --- |`;
   - вводный абзац недели («Итог недели: …») до первого урока можно не переносить.
   Текст переносить дословно. Образец — `tools/src/weeks/week-01.md`.
3. Если менялась вкладка «Tab 1», обновить `tools/src/main.xml`: это поле `data.xml` из ответа
   `read` по узлу этой вкладки с payload `{"kind":"view"}` (ответ большой и сохраняется в файл —
   извлечь xml через python, не перепечатывать).
4. Запустить `tools/build.sh`, проверить, что число полных уроков выросло и ошибок нет.
5. Закоммитить и запушить в `main`. GitHub Pages обновится сам за 1–2 минуты,
   а установленное приложение подтянет новые уроки при следующем открытии с интернетом.
