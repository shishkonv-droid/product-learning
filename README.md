# Продакт-обучение — PWA

Мобильное веб-приложение для прохождения программы «Продакт-менеджер: программа обучения на 6 месяцев»:
120 уроков, урок дня, отметки о прохождении, журнал продакта, чек-лист грейда. Работает офлайн.

Прогресс и записи хранятся только в браузере телефона (localStorage). Резервная копия — раздел «Журнал» → «Скачать копию».

## Обновить контент
`tools/build_data.py tools/src/main.xml tools/src/week1.md > data.js`, затем поднять `VERSION` в `sw.js`.
